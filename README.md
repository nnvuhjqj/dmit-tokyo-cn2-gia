# 日本 VPS 評測：拆解東京 CN2 GIA 與國際線路真實延遲，附 DMIT 全套餐價錢與選購建議

搜「日本 VPS 評測」的人，通常不是想知道「日本機房好不好」——這個問題沒什麼懸念，東京的網路基礎建設在亞太區是第一梯隊。真正的問題是：為什麼同樣標著「日本東京」，有人 ping 出來 45ms，有人跑出 200ms，還有人晚高峰直接掉到 1MB/s。

答案幾乎全在線路上，而不是在 CPU 型號或硬碟跑分上。這篇就從線路開始拆，然後把 DMIT 東京機房目前官網在售的每一款套餐、價錢和限制列清楚。

## 先搞懂：東京機房的三種線路，價差可以到三倍

把「日本 VPS」當成一個整體來比價，是最容易踩坑的做法。東京機房到中國大陸的實際體驗，取決於回程走哪條線，大致分三檔。

**CN2 GIA 級別（電信頂級專線）**：去程回程都走電信骨幹，不經過公共交換節點。東京到上海、北京的延遲通常落在 55–80ms，晚高峰不容易堵。這一檔最貴。

**CMIN2 / CMI 級別（移動國際出口）**：對移動用戶友善，三網回程強制走 CMI。移動用戶體感會比 CN2 GIA 好，電信用戶則未必。

**國際 BGP（NTT、IIJ、Lumen 之類）**：純國際線路，完全沒有針對中國大陸做優化。價格最低、流量給最多，但電信去程常常繞路——有評測記錄到東京 T1 方案的國內平均延遲約 204ms，比部分美西優化線路還慢。

一個反直覺的事實：日本離中國近，不代表網路快。低價「東京機房」如果回程繞道美國聖何塞，ping 值可以比香港還高。所以看評測時，第一件事是找 traceroute 截圖，而不是看商家宣傳頁上的「日本原生 IP」。

## 延遲、硬碟、解鎖：第三方實測數據怎麼讀

網路上關於 DMIT 東京的評測數據不少，但彼此測的方案不同，直接橫向比較會誤導。以下是能對得上號的幾組。

TYO.AS3.Pro.TINY（1 核 1GB，月付 $21.90）在 Debian 12 下的測試結果：CPU 識別為 AMD EPYC 7443P，單線程約 2.84GHz，Sysbench 單線程 3612.79，Geekbench 5 單核 977、多核 954；Fio 1M Q1 順序讀取 340MB/s、寫入 1051MB/s；亞洲節點上下行基本能跑滿 1Gbps 埠。

TYO.AS3.EB（已下架，僅供對照）的評測記錄中，國內平均延遲約 75ms，硬碟 I/O 讀寫約 949MB/s，能解鎖 YouTube、Netflix、Amazon Prime Video。

TYO.AS3.T1 的評測記錄則顯示國內平均延遲約 204ms，硬碟 I/O 約 860MB/s——硬體一如既往地好，慢的是線路。

> 三組硬體跑分接近，延遲差了將近三倍。這就是線路的價值所在，也是為什麼單看「CPU 是 EPYC」沒法判斷一台機器適不適合你。

## DMIT 是什麼來頭，跟選東京機有什麼關係

DMIT 是一家在美國紐約註冊的服務商，2017 年前後開始做 VPS 業務，機房分佈在洛杉磯、香港、東京三地。

對選購決策有實際影響的一點：它不是轉賣上游資源的二房東，而是自己持有帶寬資源，與中國三大運營商直接簽約。好處是線路出問題時溯源快，也不太會出現「上游超賣導致晚高峰掉速」這種情況。東京機房落在 Equinix TY8，Pro 系列用的是 AMD EPYC 7003（Milan）平台加 NVMe SSD。

付款方式對中文用戶友好：支付寶、微信、PayPal、信用卡都支援，也有中文客服。

## 該買 Pro 還是 T1：三種情境直接對號

把價格和線路放一起看，選擇其實不複雜。

**需要日本 IP，而且服務對象在中國大陸或日韓兩地都有**——選 Pro。東京 Pro 到上海約 55–80ms，到日本本地 1–10ms，這個組合是香港或美西都給不了的。1 核 1GB 的 Pro.TINY $21.90/月，比同段位的香港 CN2 GIA 便宜將近一半，作為入門測試的成本可以接受。

**只是要一台東京落地機，跑監控、備份、國際業務，或者服務東南亞與歐美用戶**——選 T1。年付 $36.90 的 T1.WEE 是整條產品線門檻最低的入手價，而且流量跑完只降到 50Mbps 繼續跑，不會斷。

**吃得下 $239.90 年付的預算，又剛好碰上 Shinagawa 有貨**——直接拿。同樣是三網 CTG GIA 回程，2GB 記憶體、60GB SSD、800GB 流量、500Mbps 埠速，換算下來每個月的成本比常規 STARTER 還低。

有一類人要提醒一下：如果你圖的只是「離大陸近、延遲低」，而且不需要日本 IP，那香港 Pro 才是更直接的答案，東京到大陸的延遲差不多是香港的三到五倍。日本機房的價值在於「日本本地低延遲加上回國不繞路」，兩個需求缺一個，性價比就站不住。

## 幾個容易被評測文略過的限制

**Pro 系列的流量是硬上限**。用完直接暫停帳戶，不會自動降速。500GB 的 TINY 拿來跑影片中轉或大流量代理，一兩週就能見底。T1 系列在這點上寬容得多，超量後仍保有 50Mbps 到 1Gbps 的頻寬。

**好方案長期缺貨**。東京 Pro 經常處於售完狀態，Shinagawa 更是補貨即秒殺。想買得盯著補貨通知，或者先買低配方案用著。這是供給端的現實，不是行銷話術。

**換 IP 有免費週期**。IP 被牆是海外 VPS 的常見狀況，DMIT 提供定期免費更換 IP 的服務，超出週期則按次收費，具體規則與費用依官網當下說明為準。

**部分平台在機房 IP 上會被攔**。從評測記錄看，串流平台如 Netflix、Disney+、Amazon Prime Video 的日本區解鎖表現不錯，但部分 AI 服務會對機房 IP 做 WAF 限制——這是機房 IP 的通病，跟 DMIT 本身無關。

**Pro 與 T1 都只提供 Linux 為主的系統選項**，T1 系列要到 4GB 記憶體以上才支援 Windows，Pro 系列目前不提供 Windows。要跑 Windows 應用的人得先確認清楚。

## 常見問題

**東京 Eyeball 還能買到嗎？**
目前官網東京區域已經不再顯示 EB 系列。網路上大量 EB 評測是舊資料，參考硬體表現可以，當成在售方案就會白跑一趟。

**月付還是年付划算？**
Pro 系列年付能拿到循環 8 折，T1 季付以上能拿到 7 折，差距不小。但 Pro 系列長期缺貨、補貨節奏不定，第一次入手建議先月付跑一輪，確認線路符合預期再轉年付。

**$21.90 一個月的日本 CN2 GIA 算貴嗎？**
放在東京 CN2 GIA 這個細分市場裡，這是偏低的起價。但一台 1GB 記憶體、500GB 流量的機器能承載的業務有限，實際預算要按你的業務量往上排，而不是按最低價去估。

**測試 IP 是多少？**
公開可查的東京 Pro 測試 IP 有 154.12.190.32 與 45.88.193.112，T1 系列另有一組。建議先用測試 IP ping 一輪，尤其是晚間 20:00–22:00 這個時段，比白天數據有參考價值。

看完這些，選購的判斷其實就落在一個問題上：你要的是「日本節點」還是「日本節點加上回國不繞路」。前者挑 T1，後者只有 Pro 值得考慮。至於那些標著同樣價格卻不寫清線路的商家，跳過就好。
